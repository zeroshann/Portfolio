## About

Hi! I'm John Kristian Shine Carro, a Computer Science student at Batangas State University with a focus on frontend development. This site is where I showcase the projects and certificates I've worked on so far.

## Sections

- **Home** — Introduction with a profile photo and links to my socials
- **About** — A timeline of my journey so far, from starting my CS program to my current projects
- **Projects** — A gallery of things I've built, including a Parking Lot Management System and MoisTer
- **Certificates** — Certificates I've earned
- **Contact** — A form to get in touch with me

## Built with

- HTML5
- CSS3 (custom, no framework)
- [Bootstrap Icons](https://icons.getbootstrap.com/)
- Google Fonts (Poppins)
- Deployed on [Vercel](https://vercel.com)

## Running locally

1. Clone this repo
2. Open `index.html` in your browser, or serve it with a local dev server like VS Code's Live Server extension
